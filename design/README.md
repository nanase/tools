# デザイン

サイトの見た目と動作の決定をまとめた資料である。コンペ（A・B・C の 3 案と折衷の D 案）とその後の改訂で決めたことを残し、モックだけでは読み取りにくい意図も書く。

実装はモックとこの資料に忠実に従う。食い違う判断が要るときは、実装する前に確認を取る。

## 文書

| ファイル | 中身 |
| --- | --- |
| [site.md](site.md) | 上部バー・メニュー・トップ・色・動き |
| [page.md](page.md) | ツールページの枠・配置・単独・比較・一覧・数値と式・設定の保存 |
| [input.md](input.md) | 入力の行 |
| [instruments.md](instruments.md) | 楽器のページの演奏の枠と MIDI の枠 |
| [card-art.md](card-art.md) | カードの図柄の決まり |
| [pages/](pages/) | ページごとの決定。ファイル名は `src/data/tools.ts` の `id` |

ページだけの決定は `pages/<id>.md` に書く。色・画面と操作・カードの図柄のように、ほかのページにも効く話でも、そのページで決めたことならそのページの文書に置く。2 つ以上のページに共通する決まりになったら、共通の文書へ移す。

括弧の日付は決めた日である。「ユーザーの判断」「ユーザーの指摘」は、ユーザーが決めたか指摘したことを示す。

## モック

1.0 リニューアルの確定デザインは [mockup.html](mockup.html) である。

- ブラウザで直接開ける。`#home`（トップ）と `#timer555`（タイマ IC 555）の 2 画面がある
- 入力の部品は 2026-10-07 に作り替えた。入力は [input.md](input.md) がモックより優先する
  - モックの入力の形は過去の確定版として残す
- レイアウトと操作を確かめるために 1 ファイルへまとめたものである。次の点はモックだけの仮のもので、実装では置き換える
  - 数値・ロゴ用の書体 Fira Mono を Google Fonts から読んでいる。本番では自前でホストする
  - 動くのは 555 だけで、ほかのツールへのリンクはトーストを出すだけである
  - 出典のデータシート（TI LM555）は仮に選んだものである

オシロスコープとスペクトラムアナライザの確定デザインは [audio-mockup.html](audio-mockup.html) である（2026-10-01）。
