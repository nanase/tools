# デザイン（確定版）

[mockup.html](mockup.html) が 1.0 リニューアルの確定デザインである。実装はこのモックに忠実に従う。モックと食い違う判断が必要になったら、実装する前に確認を取る。

モックはブラウザで直接開ける。`#home`（トップ）と `#timer555`（タイマIC 555）の 2 画面を持つ。

オシロスコープとスペクトラムアナライザは [audio-mockup.html](audio-mockup.html) が確定デザインである（2026-10-01 決定）。上部の帯で 2 画面を切り替える。この帯はレビュー用で、ページには入れない。

入力の部品（数値と選択肢の行、畳む入力）は、2026-10-07 に案 B（数値をドラッグして変える）へ作り替えた。入力については下の「入力（2026-10-07 決定）」の節がモックより優先する。モックの入力の形は、過去の確定版として残す。

## 決定事項

コンペ（A・B・C の 3 案と折衷の D 案）とコメントによる改訂で決まった事項である。モックだけでは読み取りにくい意図を残す。

### 全体

- 上部バーは濃色で、左にロゴとサイト名、右にテーマ切替とメニューを置く
  - どちらのボタンもアイコンだけにする
  - テーマ切替はメニューの左に置く
  - トップへはロゴで戻る。「一覧」のようなリンクは置かない
- ツールページで見出しが上部バーの下に隠れたら、サイト名の表示をページ名に切り替える
  - 切り替わった状態で押すとページの先頭に戻る
- メニューはカテゴリ別のツール一覧と絞り込み欄だけにする
  - 下部にリンクは置かない
  - Ctrl+K で開く
- フッターは注記の一文と GitHub アイコンだけにする
- パンくずリストは置かない

### 色

- オレンジ（`--accent`）は、メニューの LED と現在地を示す印、再生中などの LED だけに使う
- 選択状態はインク色の塗りにする。強調は色ではなく文字の大きさと太さで行う
- 信号色は波形と回路図の範囲だけで使い、UI の装飾に流用しない
- コードの色分け（SVG テーマスキーマチェッカー）は、信号色ではなくコード専用の色を使う（2026-09-27 決定）
  - 黄は出力、シアンは C1 の電圧
- スペクトログラムは、テーマに依らず黒い地にする。色は強度の弱い順に 黒 → 紫 → 青 → 緑 → 赤 → 白 で、テーマに依らない（2026-10-01 決定）
- 入力レベルのメーターは標準の緑にし、−3 dBFS を超えた分は警告色にする（2026-10-01 決定。audio-mockup.html の灰色から変更）
- チューナー（2026-10-16 決定）
  - 12 音のストロボの窓は、機械式のストロボのようにテーマに依らず暗い地に明るい縞で描く
  - ♭・♯ の灯りは LED としてオレンジ、合っている印（中央の灯り・合格の帯・合っている窓の枠）は入力レベルのメーターと同じ緑。合うと 3 つの灯りがすべて点き、色だけに頼らない
- 音律とうなり（2026-10-23 決定）
  - 一致する部分音と、うなりに合わせて明滅する灯りは信号色の ch1。表と拡大図の灯りも図と同じ色にし、うならない組（純正・部分音がない）は消えた LED の色
  - 鍵盤の色はピアノ音響モデルと同じ。和音の音は ch1 を混ぜ、根音は下端に ch2 の線
- ピアノのアクション（2026-10-23 決定。デザインのキャンバスの案 B）
  - 部品は線の色で分け（鍵は木の茶、ウィッペンは青、ジャックは緑、レペティションレバーは黄、ハンマーは紫、ダンパーは灰）、図の上の凡例で名前を示す。部品名の引き出し線は引かない
  - 力を伝えている接触だけを、LED と同じオレンジの小さな点で描く。色のない小さな部品（弦・レットオフボタン・ドロップねじ・バックチェック）だけ、線なしで名前を添える
  - 接触の点にマウスを乗せる（タッチでは押す）と、接触の名前と押す力を吹き出しに出す。レットオフボタン・ドロップねじ・バックチェックは、部品か名前に乗せると役割の説明を出す（2026-10-24）
  - 時刻とハンマーの速さ・弦までの距離は、図の右上に出す。図の右の説明は段階の名前と説明だけにする（動く部品・力を伝える接触の一覧はやめた。2026-10-24）
  - 再生の操作は楽器のページの演奏の枠と同じ形（最初へ戻す・再生と一時停止・位置の欄）にし、右端に前・次の段階とくり返しのボタンを置く。位置の欄は段階ごとに長さの対数で幅を割り、どこを押してもドラッグしてもその位置へ移る（2026-10-24）
  - 再生の速さは 自動・1/100・1/200・1/500（2026-10-24 に 1/1000 をやめた）
  - ハンマーが弦を打つと、打った点から弦を伝わる山と、まわりへ広がる輪を描く。スローでも止めていても実時間で 2.4 秒かけて広がって消える（2026-10-24）
- 初期の配色は CSS の `prefers-color-scheme` だけで決め、JS に頼らない
  - ページ読み込み時にトランジションを走らせない

### 枠

- 枠は C 案の形にする。背景のない細い線に、見出しを枠線の上に載せる
- 補足（「定常状態」など）とボタン（E6/E12/E24）は、枠線の上の右端に載せる
- 開閉できる枠（動作原理と式）は、閉じているときは見出しの載った水平線だけにする
- 初期状態は閉じる
- ほかの枠も見出しを押して開閉できる。初期状態は開く（2026-10-22 決定）
  - 開閉しないのは、ページ上部で幅いっぱいに置いた中心の図（エンジン・指板・管と鍵盤・鍵盤と弦・空・トランペット・メータ・ヴァイオリン・アクションの段階とアクション）と関連ツールだけ。2 列のページはすべての枠を開閉できる
  - 閉じても、枠線の上の右端の補足とボタン（再生・停止、E6/E12/E24 など）は残す
  - 枠の開閉はブラウザに保存し、再読み込みしても戻す。描く前に戻すので、開いた枠が閉じて見える動きは出ない

### ツールページ

- 説明文は常時表示しない。見出しの右の小さな「?」から吹き出しで出す
- 入力は A 案のパラメータ表の形にし、列見出しは置かない
  - 行の形は「入力（2026-10-07 決定）」の節に従う
  - プリセットは小さい順に並べる
  - 入力中は結果を動かさない。Enter か欄の外で確定する
  - 項目の補足は常時表示しない。項目名に点線を引き、ホバーかタップで吹き出しに出す（2026-09-27 決定）
- 枠全体の表示を切り替える選択肢（フィルタの種類、コイルの形、入力元、再生）は、枠線の上の右端に載せる（2026-09-27 決定）
  - 開始・停止のような二択は、枠線の上の右端の LED 付きの小さなトグルにまとめ、二択だけの行は置かない（2026-10-01 決定）
  - 楽器のページの演奏の枠は例外で、枠線の上の右端には状態だけを出す（2026-10-18 決定。下の「楽器のページの演奏の枠」の節）
- 図の表示を変える設定（時間軸・振幅・トリガ、周波数軸・強度の範囲など）は、その図の下に「表示の設定」などの見出しでまとめて畳む（2026-10-01 決定。形は 2026-10-07 に「入力」の節のものへ変えた）
- 音をスピーカーで鳴らす操作は「音」「モニター」の別の枠にし、枠線の上の右端に再生・停止、中に音量（初期値 −30 dB）を置く（2026-10-01 決定）
  - 音声の入力元の初期値はマイクで、どの入力元も止めた状態で始める。マイクの間はハウリングを避けるためモニターを使わず、モニターの枠ごと畳んで開けなくする（2026-10-01 決定。audio-mockup.html のテスト信号から変更）
- 計算結果は B 案の形にする
  - 周波数を全幅で大きく出し、残りを罫線で区切って並べる。最下段の下に線は引かない
  - 「理想素子モデル」のような注記はフッターと重複するので置かない
  - 枠の幅に合わせて 2・3・4 列に並べる。補足の行が長い結果は 3 列までにする（2026-10-01 決定）
  - PC では、計算結果が画面にない間だけ、画面の下に要約の帯を出す（2026-10-01 決定）
- 出力波形は C 案のオシロスコープ表示を英語表記ごと使う
  - カーソル位置の読み値は、表示窓の下に右寄せで出す（2026-10-01 決定）
  - 1 つの枠で表示を切り替えるとき（波形とリサジュー、スペクトラムとスペクトログラム）は、図の下の設定も切り替えた表示のものに入れ替える。両方に効く設定は残す（2026-10-01 決定）
- 音声の振幅は、フルスケールを 1 とした値（FS）と dBFS で表す。実効値・ピーク・スペクトラムのどれで測っても、正弦波が同じ dBFS になるようにする（AES17 の決め方。2026-10-01 決定）
- 回路図は B 案のものを使い、出力波形の下に置く
- 計算結果・測定値（結果の枠、要約の帯、カーソルの読み値、代入した式で計算した値）は、有効数字の桁をそろえて末尾の 0 も残す（例 440.30 Hz・1.000 kHz）。数値欄・入力欄・プリセット・メッセージは末尾の 0 を落とす（2026-10-01 決定）
- 入力と表示の設定はブラウザに保存し、開き直したときに戻す。見出しの右端に「設定をもとに戻す」アイコンのボタンを置き、保存した設定を消して既定値で開き直す。保存する設定がないページには置かない（2026-10-01 決定）
  - 動作の状態（JJY シミュレータの動作・停止、RUN・STOP、開始・停止）は保存しない
  - 「その他」と「表示の設定」の開閉も保存する。既定値に戻した項目は保存から消す（2026-10-07 決定）
  - 枠の開閉も保存する。保存する設定ができた SVG テーマスキーマチェッカーにも、「設定をもとに戻す」ボタンを置いた（2026-10-22 決定）
- 分数は組み文字（⅓）を使わず「1/3」と書く
- 数式は本文中の記号を含めてすべて MathML で書き、出典を添える
- 動作原理と式は、枠の幅いっぱいに組む（2026-10-09 決定。段落の幅の上限 62ch を外した）
  - 節ごとに見出しを付け、段落を短くし、並列の事柄は箇条書き・記号の説明・表にする
  - 処理の流れは矢印でつないだ箱（.flow）、制御系はインラインの SVG で描く。Mermaid は重いので使わない
  - 式の箱では、短い式を横に並べる
  - 出典は枠の最後に番号付きの一覧にし、用途と書誌を分けて並べる。本文には番号（[1]）を付ける
  - 文献に基づかない値や方法は「このツールで決めたこと」の節に箇条書きで並べる
- 関連ツールは、スマホでは 3 件、それより広い画面では 1 行に収まる件数だけ出す
- 操作説明の段落は置かない。UI だけで使い方が分かるようにする

### 入力（2026-10-07 決定）

入力の UI の改良案（現状・案 0・案 A〜D）から、案 B（数値をドラッグして変える）を採用した。数値の 1 行は約 130〜190 px から約 38 px になる。ユーザーの判断は「コンパクトにまとまっており、スライダーと一体化しているのは良い」で、直接入力することは少ないため、直接入力は押して開く形で残した。

- 数値の行は、記号・項目名・数値欄・単位・↺ を 1 行に並べる。スマホでも 1 行にする
- 数値欄そのものがスライダーで、左右にドラッグすると値の並び（E 系列・与えた並び・一様な刻み）を移る
  - 4 px 動くまではドラッグとみなさない
  - 1 刻みの距離は並びの長さで決め、2〜14 px にする
  - タッチでは横に動かしたときだけ値を変え、縦のスクロールを妨げない
- 欄の地に、範囲の中の位置を薄く塗る
  - ± の量（増幅量・流速など）は 0 から左右へ塗る
  - 今の値の縦線は、欄の上下の端だけに描く。値の文字に重ねないため（案は欄の高さいっぱいの線）
  - 欄の下端の小さな刻みは、プリセットの位置
- 欄の両端の ‹ › で、前・次の値へ移る。行き先の値は title と読み上げに出す
- キーボードでは、← → ↑ ↓ で 1 つずつ、PageUp・PageDown で大きく、Home・End で端へ動かす
  - Enter か数字を打つと入力欄を開く
- 動かさずに離すと入力欄に変わり、下に吹き出しを出す
  - 吹き出しには、範囲・プリセット・「既定値 …」のボタンを並べる
  - Enter か欄の外で確定し、Esc で戻す
  - 入力中の「→ 値」と読めない値の知らせは吹き出しに出す。確定したあとの知らせ（範囲外の丸めなど）は行の下に出す
- 使わない行は、数値欄を破線にして理由（「LPF では使いません」など）を出す
- なくしたもの: ▲▼ の下の行き先の値、スライダーの目盛りの数字、常に見えるプリセット
- 選択肢の行は、区切りボタンを項目名の右に置いて 1 行にする。選択肢の多い行（チップ）は項目名の下に並べる
- 既定値（ページを初めて開いたときの値）と違う行は、左端に細い線を引き、行末に ↺ を出す
  - ↺ の場所は空けておき、出し入れで行がずれない
  - 枠の見出しの右に「↺ n」を出し、その枠の入力をまとめて既定値に戻す（2026-10-09 に「件」を外した）
  - 狭い画面で枠の見出しと重なるときは「↺ n」を出さない。行末の ↺ とページ見出しの ↺ は残る
  - ページが使わない間だけ隠している行（1 層のときの層の構成など）は数えない
  - ページ見出しの ↺（保存した設定をすべて消す）は変えない
- 使う機会の少ない入力は、行ごとに畳まず、枠の下の「その他」にまとめて畳む
  - 見出しと開閉の印を左、今の値の要約を右端に置き、開閉で見出しは動かない
- 図の下の表示の設定も「その他」と同じ形にし、見出しを枠に合わせる（「表示の設定」「表示とトリガの設定」など）
  - 中が 700 px 以上の広い枠だけ 2 列に並べる。狭い列に 2 列で並べると、1 行に並べた行では項目名が詰まるため
- 楽器のページの演奏の枠のテンポと音量、オルガンのスウェル、FM 音源のオペレータの周波数比と強さも、同じ数値の行にそろえる
- 不採用の案は、案 0（今の行のまま詰める）、案 A（細い行と小さなスライダー）、案 C（一覧と、開いた 1 項目だけの入力）、案 D（つまみ）

### 楽器のページの演奏の枠（2026-10-18 決定）

ピアノ・オルガン・ギター・ヴァイオリン・トランペットの演奏の枠を、案 A〜C から案 B（枠の中のトランスポート）に作り替えた。それまでの枠には、曲を止めるボタンが 2 つ（見出しの「停止」と「すべて止める」）あり、止めると位置が消えた。見出しのトグルを一時停止のつもりで押すと、曲が頭からになった。ユーザーの評価は「押しやすさ、わかりやすさ、曲の位置のわかりやすさ、文字に頼りすぎていない部分」である。

- 演奏と一時停止は、枠の中の大きな丸いボタン 1 つにする
  - 一時停止は曲を止めるだけで、音の処理（AudioContext）は止めない。一時停止の間も手で弾ける（2026-10-22 変更。それまでは AudioContext ごと止めていたので、手で弾けなかった）
  - 一時停止したときに鳴っている音は、楽器ごとに自然に離す。ピアノは鍵とペダルを、オルガンは鍵を離し、ヴァイオリンは弓を離し、トランペットは息を止める。ギターは弦を鳴らしたままにする
  - 一時停止しても位置は残り、次に押すと止めた拍から弾く。その拍で伸ばしている音は、残りの長さで弾き直す（位置の欄で移ったときも同じ）
  - 演奏中は、ボタンのまわりに薄い輪を付ける
- 枠線の上の右端にはボタンを置かず、状態だけを出す
  - 演奏中は点いた LED と「演奏中」、一時停止中と途中の小節で止まっている間は輪の LED と「一時停止中」。曲の頭で止まっている間は出さない
- ボタンの右に、小節の目盛り付きの位置の欄と「小節 / 小節の数」「経過時間 / 曲の長さ」を並べる。左には曲の頭へ戻すボタンを置く
  - 位置の欄を押すかドラッグすると、その小節の頭へ移る。演奏中はすぐそこから弾き、止まっている間は次に演奏したときにそこから弾く
  - 曲の頭へ戻すと、演奏中なら頭から弾き直し、一時停止中なら一時停止を解いて止める
  - 欄の位置は時間に比例させる。目盛りは 1 小節ごとで 4 つおきを長くし、狭いときは 2・4・8 … 小節おきに間引く
  - 時間は今のテンポでの長さ
  - 曲を変えたときと、曲の終わりまで弾いたときは頭に戻る。手で弾いて曲を止めたときは、その小節から弾けるように残す
- 楽器ごとの音の操作（リリース・弓を離す・消音）は、右端の小さなアイコンのボタンにする
  - 「すべて止める」は「消音」にし、曲の演奏は止めない
  - ヴァイオリンとトランペットは、曲の続きがすぐ鳴るので、曲の演奏中は消音を使えない
- 演奏の操作のキー（Space など）は付けない。トランペットでは Space が「吹く」に当たる
- 不採用の案は、案 A（見出しのトグルを再生・一時停止にし、位置は数値の行にする）、案 C（曲の起伏をスコープの画面に描き、押した小節から弾く）

- 絞り込み欄とカテゴリのボタンは枠で囲まない（2026-09-27 決定）
- カードの図柄は、各ページが描いている図や信号を縮めたものにする（2026-10-14 決定）
  - JJY シミュレータは秒の扇とタイムコード、ノイズジェネレータは波形と LFSR、ギターは横に倒したギター、ピアノは上から見たグランド、オルガンはパイプの正面、エンジンはシリンダとクランクと排気、SVG テーマスキーマチェッカーは明るい地と暗い地の 2 枚に描き直した
  - 図柄は時刻の関数として src/lib/card-art.ts に書く。止まっているときの絵はビルド時に HTML へ出す
  - ヴァイオリンは、ページの「上から」の図（楽器の形は同じデータ）を縮め、弓で A 線を擦る絵にした（2026-10-14）。弓は実物の長さで描き、元から先まで弓をいっぱいに使って往復させるので、毛箱と頭が交互に見える（中ほどの印は付けない。ユーザーの希望）。弦は Helmholtz の運動の折れ目が回る
  - ハロ（暈）は、太陽のまわりの内暈・幻日・上端接弧・環天頂アークを描く（2026-10-16）。太陽がゆっくり昇り沈みし、幻日は太陽が高いほど内暈から離れ、環天頂アークは太陽高度 32° を超えると消える。位置はページと同じ解析の式で決める
  - フォーカシングマスクは、バーティノフマスクの正面と、星の 3 本の光条を並べた（2026-10-16）。ピントが前後し、中央の光条が X の交点の上下を通る
  - 日食は、月が太陽を横切る絵と、光の量の曲線の上を進む点にした（2026-10-16）
  - チューナーは、ページの針のメータ（合格の帯と純正律の ▼）を縮めた絵にした（2026-10-16）。3 秒ごとに弾き直し、低めから振れて 0 に落ち着く
  - トランペットは、マウスピース・リードパイプ・主管抜差し・ピストン・ベルの線画にした（2026-10-16）。ハ長調の音階の指使いでピストンを押し、管の中を圧力の波が進み、ベルから音が広がる
  - ピアノのアクションは、ページの横から見た図（鍵・ウィッペン・ジャック・レペティションレバー・ハンマーと弦、部品の外形は同じデータ）を縮めた絵にした（2026-10-23）。高さで倍率が決まるので、鍵の前の端は少し切る。色はページに合わせ、ウィッペンを ch2、レペティションレバーを ch1 にする（ほかの部品の色はカードの変数にない）。3 秒ごとに鍵が沈み、ジャックが抜けたハンマーが弦を打って弦が振れ、ハンマーはバックチェックに止まり、鍵が戻ると弦も止まる。動きは計算せず、角度のキーフレームでつなぐ
- カードにマウスを乗せている間、図柄ごとにページの中身を短く再生する（振子が揺れる、クランクが回る、ビットが送られる、など。2026-10-14 決定）
  - 関連ツールの欄のカードも同じにする
  - 不採用の案は、輝線が左から図柄を描き直す「掃引」

### 動き

- テーマ切替、メニュー、吹き出し、開閉にはトランジションを付ける
- OS で動きを減らす設定がオンのときは、動かさずに切り替える
- マウスを乗せて動かすもの（上部バーのアイコン、カードの図柄）は、マウスのときだけ動かす。タッチと、動きを減らす設定のときは動かさない
