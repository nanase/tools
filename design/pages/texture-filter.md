# テクスチャのフィルタ

2026-11-20 にデザイン案 3 回目を採った。図としくみを 1 つの映像にまとめ、映像の下の工程のボタンで上に載せるものを変える。2026-11-21 に、映像を「床が流れる図」から「道路を走る映像」に一本化した。

- 1 回目は 4 案を出した
  - A 案: ゲームの画質設定（フィルタ・ミップマップ・異方性の倍率・段を色で）
  - B 案: 画素の足あと（1 画素が覆う範囲と読む画素を拡大）
  - C 案: 左右で比べる（境目を動かす。文字の模様は「止まれ」）
  - D 案: 小さな絵を重ねる（段を選ぶと床の使う所が光る）
- ユーザーの評価は、A 案と C 案がわかりやすく、解説としては D 案が最も興味深い
- 2 回目は床の右上で単独と比較を切り替え、しくみの枠を床の下に分けた
  - 床としくみの図が上下に分かれていて見づらい、とユーザーが指摘した
- 3 回目でしくみの枠をなくし、床の図を工程と共有した
- 実装のあと、画素の足あとの工程を外し、文字（止まれ）の模様を細い縞に替えた（2026-11-20、ユーザーの判断）
  - 足あとは分かりにくい、と指摘された
  - 「止まれ」が並ぶと怖いので、文字の模様は使わない
- 面白さを足す案 9 つ（2026-11-20）から「道路を走る」が選ばれ、試作を経て映像をこれだけにした（2026-11-21、ユーザーの判断）
  - 昔のレースゲームのように、アクセルとブレーキで速さを変え、速さによる見え方の変化を見せる
  - 模様の切り替え（市松・タイル・細い縞）はなくした
  - ハンドルは付けない。車は左車線を道に沿って走る
  - 試作と最初の実装では後ろから見た車を出していたが、音がバイクなので、乗っている人の目から前を見た眺めにして車は映さない（2026-11-21、ユーザーの判断）
  - 不採用の案はトンネルと異方性の花・ちらつきメータ・正解と比べる・遠くだけ別の絵・模様を描く・床に近づく・縞の細かさ・どのフィルタ？

## ページ

| 項目 | 値 |
| --- | --- |
| `id` | `texture-filter` |
| ページ名 `t` | テクスチャのフィルタ |
| カテゴリ `c` | CG |
| 図柄 `ic` | `tf` |
| 説明 `d` | 遠くの道路の白線がちらつく理由とフィルタの効き目を見ます。 |
| 関連 `r` | 画像の拡大縮小・シェーディング・標本化定理・レイトレーシング |

- 関連は [site.md](../site.md#カテゴリと関連ツール) の基準を満たすよう、画像の拡大縮小とシェーディングの `r` にもこのページを入れる
- `k` にはミップマップ・LOD・最近傍・バイリニア・トライリニア・異方性・モアレ・エイリアシング・レースゲームなどを入れる

## 映像の描画

- 道路・草・空・山を 1 枚のシェーダで画素ごとに描き、その上に木を遠い順に重ねる（WebGL2）
- 詳細度（LOD）と異方性の分け方は GPU に任せず、シェーダで式どおりに計算する
  - どの GPU でも同じ見え方にするため
  - 段の中のバイリニアだけを `textureLod` に任せる
  - 木も同じフィルタで読む
- ミップマップは自前で作る
  - 道路は 256 × 256 画素で横 16 m・縦 20 m を覆い、9 段
  - 木（とがった木と丸い木）は 64 × 64 画素で 7 段。透明な所の色が混ざらないよう、不透明度で重み付けして平均する
- 映像は CSS の 1 画素を 1 画素として描く。端末の画素密度に依らず同じ粗さで見える

| もの | 決まり |
| --- | --- |
| カメラ | バイクに乗っている人の目。左車線の中心、高さ 1.2 m、縦の画角 44°、見下ろす角度は初め 5° |
| 道路 | 片側 1 車線の 2 車線。中央の破線は 8 m 引いて 12 m 空ける。外側に白線、縁石は 2.5 m ごとに赤と白 |
| 草 | 10 m ごとに明るい帯と暗い帯 |
| 曲がり | 道の曲率は進んだ距離でゆるく変わり、前方 d の道を 0.5·曲率·d² だけ横へずらす。山は道の向きの変化で横へ流れる |
| 木 | 道の両側 6〜15 m に、高さ 5〜9 m。300 m ごとにくり返し、5〜260 m 先を描く |

## 走る

- アクセルとブレーキは押している間だけ効く。ハンドルはない
  - アクセルは速いほど弱く効き、最高は約 200 km/h
  - ブレーキは強く効く
  - どちらも離すと、その速さを保つ（ユーザーの判断）
- 操作は映像の下の隅のボタン（左がブレーキ、右がアクセル）と、キーの ↑・↓（W・S でも可）
  - キーで運転するのは、ページの枠の中にいるとき（映像やボタンを押したあと）だけ。入力欄とスライダは除く
  - ページの外を押したり、タブを離れたりしたら離す
- 速さは映像の下の中央に km/h で出す
- 速さとアクセルは動作の状態なので保存しない

## 音

- エンジンのページのバイク（CT125・JA65）の音を、回転数を保つ運転で鳴らす（変速機のページと同じ `EngineAudio`）
  - バイクの最高は約 85 km/h なので、映像の速さを 200/85 で割ってバイクの速さにし、ギアと回転数を決める（ユーザーの指摘）
  - 回転数が 5,500 rpm を超えたら上のギアにする（ドップラー効果のページと同じ）
  - スロットルはアクセルで全開、ブレーキで閉じる。離して速さを保つ間は 0.35、止まっている間は 0.08（アイドリング）
- 「音」の枠の右上に再生・停止、中に音量（エンジンのページと同じ行、既定 −12 dB）
  - アクセルを踏み続けたときに −26 LUFS 前後（耳で +8 LU）になるよう、`bun run loudness` で合わせた
- 初めは止めておく。スマートフォンで画面が隠れたら止める

## 画面と操作

### 並べ方

- 映像の枠は中心の図なので開閉しない
- 幅 1,100 px 以上では、映像を左（2/3）に、設定・計算結果・音を右の列に置く。映像を見ながら設定を変えられるようにするため（ユーザーの指摘）
- 幅 900〜1,100 px では、映像を幅いっぱいに置き、その下に設定を左（3/5）、計算結果と音を右に並べる
- それより狭い画面では、映像・設定・計算結果・音の順に縦に並べる
- 動作原理と式は幅いっぱいに置く

### 映像の枠

- 見出しは「映像」、工程の先頭のボタンも「映像」にする（ユーザーの判断）
- 右上に「単独」「比較」を置く
- 映像の上に工程ごとの 1 行の説明、映像の下に工程のボタン 4 つを置く
  - ボタンは [page.md](../page.md#しくみの枠) の押して選ぶ工程と同じクラスで組む
  - 初めの「映像」は工程ではないので、番号の代わりに白抜きの ▶ にする
  - どの工程でも映像は同じで、上に載せるものだけを変える。どの工程でも走れる
- 単独と比較は「映像」のときだけ選べる
- 映像の右上に全画面のボタンを置く（[page.md](../page.md#全画面)）
  - 全画面では説明・映像・工程のボタンを縦に並べ、映像を残りの高さいっぱいに広げる
  - 表示の切り替え・音の再生・設定（左右の組・木・見下ろす角度）を浮かぶ枠「設定」に入れる

| 工程 | 映像 |
| --- | --- |
| 映像 | 設定のフィルタで描く。比較では境目の左右を別の設定で描き、境目はドラッグか左右の矢印キーで動かす |
| 縮めた絵 | 道路の段の絵の組（256〜1）を左上に重ね、選んだ段を使う所だけを明るくする。触らなければ 1.1 秒ごとに次の段へ移る |
| 段を選ぶ | 使う段で道路と木を塗り分け、色の見本を上に出す |
| 境目を混ぜる | 左は段の切り替え（バイリニア＋ミップマップ）、右はトライリニア。境目は動かせる |

### 設定

- テクスチャフィルタ・ミップマップ・異方性の倍率を 1 組にし、比較では左右 2 組にする
  - 初めは左がトライリニア、右が異方性 16x
  - トライリニアと異方性ではミップマップの行を使えなくし、「いつも使います」と出す
  - 異方性の倍率は異方性のときだけ使う
- 木（あり・なし）と見下ろす角度（2〜30°、初めは 5°）は左右で共通にする

### 計算結果

- 1 画素で読むテクスチャの画素
  - 最近傍 1・バイリニア 4・トライリニア 8・異方性は最大 8 × 倍率
- 使うメモリ。ミップマップありは 1.33 倍、なしは 1.00 倍

## 色

- 映像はテーマに依らない。上に重ねる札・段の絵の組・ボタンは暗い地にする
- 段の色は 256 から赤・橙・黄・緑・水色・青・紫・灰の順。2 と 1 の段は灰

## カードの図柄（2026-11-21）

- 道路の案の R2（木のある道路）を描く（ユーザーの判断）
  - 初めは市松の床の案（流れる市松）を採っていたが、映像を道路に一本化したので描き直した
- 左車線から前を見た道路を、図柄の 2 × 2 の画素ごとに最近傍で読み、塗りの升で描く
  - 白い線と縁石の白は灰の塗り（fc）、縁石の赤は赤黒木と同じ赤（fr）
- 道の両側に木（緑の輪郭 s3 と幹）、遠くに山の稜線を細線で描く
- マウスを乗せると道と木が手前へ流れ、遠くの破線と縁石がちらつく
  - 1 秒に 12 コマ、1 周は 3 秒（60 m 進み、破線 3 本分で元の絵に戻る）
- 不採用の案は最近傍の道路（木なし）・線で描いた道路。床のころの案は段の色の帯・ピラミッドと床・画素の足あと・左右で比べる

## 用語

- trilinear は「トライリニア」と書く。GPU の解説記事（PC Watch・4Gamer）と Wikipedia の「テクスチャフィルタリング」がこの表記である
  - NVIDIA のコントロールパネルは「トリリニア」なので、検索用に `k` へ入れる
