# 赤黒木

2026-11-08 にデザイン案 A を採った。

## 画面と操作

- 赤と黒の丸の木を描く
  - x は中順の順位、y は深さにする。回転ではノードが時間をかけて入れ替わる
  - 入れるキーは塗りの札、探しているキーは枠だけの札に「?」を添え、比べているノードの右上に出す。B木の札と同じ見分け方にした
  - 不採用の案は 2-3-4木と並べる（B）・深さのバー（C）・全体と拡大（D）
- 工程は追加・検索・削除の 3 つで、押すとその工程を初めから再生する。回数は工程ごとに 0 から数える
- データ構造は赤黒木・左傾赤黒木・AA木・AVL木・二分探索木（参考）の 5 種にする
  - 2-3-4木は B木のページにあるので入れない
  - トップダウンの赤黒木・WAVL木・スプレー木・トリープ・スケープゴート木は後回しにする
- 既定はキー 31 個・2 回/秒にする。スマートフォンの幅はキー 15 個から始める
- 単独・比較・一覧（[page.md](../page.md#単独比較一覧)）を使う。枠の並びと比較の枠は B木と同じ
  - 比較の対象はデータ構造とキーの順番にする
- 「NIL の葉」を表示にすると空いた枝の先に黒の小さな四角を描く。黒の高さを数える終わりの位置を見せるため

## 色

- 比較・回転と色の変更・発見の色は B木と同じ値にする。`--rb-cmp` は比較、`--rb-mov` は回転と色の変更、`--rb-done` は検索で見つけたノード
- 赤のノードは `--rb-red`、黒のノードは `--rb-blk` で塗る。暗いテーマの黒は画面の地に沈むので、濃い灰 #2a3236 で塗って灰の縁を付ける
- 赤が続く枝と条件違反のノードは `--warn` の破線にする。赤のノードの塗りと見分けるため、破線で形も変える
- AVL木と二分探索木は色を持たないので `--rb-node` の地に数字で描く

## カードの図柄（2026-11-08）

- 赤と黒の丸の木を描き、1〜15 を順に入れる。回転で根が入れ替わり、赤が続く枝は破線になる
- 全部入れたら同じコマを逆に再生して空へ戻す。B木と同じ理由で、削除の手順を描くより短く済むため
- 止まっている絵は 10 個以上入った木で、祖父で回転した直後にする
- 赤の塗りは `fr` の class で、色は site.css の `--ic-red` にある。ほかのカードに赤の塗りがなかったので足した
- 黒のノードは灰の `fc` で塗る。真っ黒の塗りは他のカードより濃く浮いて見えたため
- 不採用の案は 2-3-4木と並べる・傾く木と傾かない木・深さのバー・回転だけ・上へ伝わる色の変更
