# マンデルブロ集合

2026-11-19 にデザイン案 E を採った。A 案（図を大きく見せ、操作を図に重ねる）を土台に、B 案のジュリア集合と C 案の式の板を、図の上に浮かぶ枠として開閉する。

ユーザーの評価は「操作感も良好で、無駄がない」である。不採用の案は次のとおりである。

- 1 回目の B 案：ジュリア集合を常に横に置く
- 1 回目の C 案：板を常に横に置く
- 1 回目の D 案：深さの目盛り・潜る行き先・足あと
- 2 回目の F 案：式そのものを押して切り替える
- 2 回目の G 案：板を図の下の枠に置く

## 画面と操作

### 図

- ページ上部の幅いっぱいに置く、開閉しない中心の図である
- 縦横比は PC で 16:10、スマートフォンで 1:1
- 図の上に次のものを重ねる。重ねる部品はどれも暗いガラスの地で、テーマに依らない

| 位置 | 部品 |
| --- | --- |
| 左上 | 種類のセレクトボックス |
| 右上 | LED トグル 4 つ（式・ジュリア集合・名所・配色）と全画面のボタン |
| 左下 | 拡大・縮小・全体のボタン（全体は家の形） |
| 右下 | 倍率（例 ×1.23×10¹⁵） |

- 倍率は、べきが整数でなく上限に着いたときだけ、横に「上限」を出す
- 図の下端に、細かい絵を作っている間の進みを細い線で出す
- 全画面では図を画面いっぱいに広げ、重ねた部品はそのまま使う（2026-11-19）
  - 倍率 1 で短い辺に全体が入る。縦長の画面でも全体が切れない

### 拡大と移動

- ホイールで拡大・縮小する
  - 指した点を動かさずに、倍率の対数を毎フレーム目標へ寄せる
  - 寄せる速さは 1 秒あたり 10 倍の割合
- ダブルクリックで 4 倍に拡大し、Shift を押しながらなら 1/4 にする
- ドラッグで移動する
- 2 本指で、つまんで拡大・縮小しながら移動する
- 全体のボタンは、今の種類の全体の絵へ戻す

### 種類と式

- 種類はセレクトボックスで 5 つから選ぶ
  - マンデルブロ・バーニングシップ・トリコーン・セルティック・バッファロー
- 選ぶと 0.75 秒かけて式を滑らかに移す
  - 混ぜる量とべきを ease-in-out でつなぐ
  - 共役は半分の時点で切り替える
  - 倍率が ×10⁴ を超えている間は、べきだけ途中を飛ばす
- 混ぜる量を途中にすると、t ≈ 0.5 で図の大部分が黒くなる。これは式どおりの形として残す（ユーザーの判断）
- 種類を選んでもべきは変えない。べき 3 のマンデルブロも、セレクトボックスには「マンデルブロ」と出す
- 板で 5 つのどれにも当たらない式にしたとき、セレクトボックスは空の選択肢を出す（このツールで決めたこと）
- どの種類も虚軸を下向きにして描く
  - 上下に対称でないのはバーニングシップとバッファローだけで、こうすると船が立つ
  - ほかの 3 つは見た目が変わらない

### 浮かぶ枠

- 右上のトグルで開閉し、初めはどれも閉じておく
- 開閉はブラウザに保存する
- スマートフォンの幅では、図に重ねずに図の下へ並べる

| 枠 | 位置 | 中身 |
| --- | --- | --- |
| 式 | 右上 | 式の表示・板・べき・共役・深い拡大の LED |
| 配色 | 右上（式の下） | 配色 6 種・色の間隔・色のずれ・陰影・色を回す |
| ジュリア集合 | 左下 | 正方形の図と c の値 |
| 名所 | 図の下端の帯 | 8 か所の小さな絵 |

式の枠は次のとおりにする。

- 式は z ← |Re (|x| + i|y|)ᵖ| + c の形で出す
  - 縦棒と「Re」の濃さで、混ぜる量を見せる
- 板の四隅には、各種類の全体の小さな絵を置く
  - 左上がマンデルブロ、右上がバーニングシップ、左下がセルティック、右下がバッファローである
  - 横軸はかける前の |x|・|y| を混ぜる量、縦軸はかけた後の |Re| を混ぜる量である
- 板のつまみは橙にする。現在地の印にあたる
- 混ぜる量は 1/1024 刻みにし、端から 0.04 以内なら端に吸い付ける
- べきは 1.5〜8 のスライダーで決め、整数から ±0.06 以内なら整数に吸い付ける
  - 倍率が ×10⁴ を超えている間は、整数にしか動かさない。深い所で整数でない値にして倍率を戻す動きは作らない
- 深い拡大の LED は、べきが整数のときに点く。表示だけで、押せない

ジュリア集合の枠は次のとおりにする。

- 大きい図の上でマウスが指した点を c にして描く
- 大きい図を押すと c を固定し、図の上の c に橙の十字を出す。もう一度押すと固定を外す
  - 押すとは、4 px 以上動かさずに 0.4 秒以内に離すことである。ドラッグとはこれで見分ける
  - ダブルクリックで拡大したときは固定を変えない。1 回目を押してから 0.25 秒待ち、2 回目が来なければ固定する
  - タッチでは指した点がないので、押した点を c にして固定する（このツールで決めたこと）
- 種類と式は図と同じにし、配色も図と同じものを使う

## 計算

### 方式

- WebGL2 で描く。WebGPU にも倍精度はないので、どちらでも摂動法が要る
- 基準の点の軌道を、BigInt の固定小数点で 1 本計算する
  - Web Worker で計算し、描画を止めない
  - 桁数は倍率に合わせて決める
- 各画素は、基準の軌道との差 δ を単精度で追う
  - 式は δ′ = (P + D)ᵖ − Pᵖ + δc とする。P は混ぜた後の基準の値、D は同じく差である
  - (P + D)ᵖ − Pᵖ は D·Σ(P + D)ᵏ Pᵖ⁻¹⁻ᵏ で計算し、計算量はべきに比例する
  - 絶対値は |X + x| − |X| を場合分けで計算する（diffabs）
- |z| < |δ| になるか基準の軌道の終わりに着いたら、δ を z に置き換えて基準の 0 番目から続ける（Zhuoran のリベース）
- 基準の点は画面の中心を先に試す。早く発散したら、周りの 8 点から最も長く発散しない点を選ぶ
- べきが整数でない間は、単精度でそのまま計算する。倍率の上限は ×10⁴ である。それより深いと、隣の画素が同じ単精度の値になる

### 深さ

- 最初の版は ×10³⁰ を倍率の上限にする。試作は rescaling と BLA なしで ×10²⁹ まで描けた
- ×10³⁰⁰ 程度へは、あとの版で次の 2 つを足して広げる
  - ×10³⁸ を超える所では、差の指数を別に持つ（rescaling）。単精度の指数の範囲を越えるためである
  - 反復の上限が大きい所では、BLA で反復をまとめて飛ばす

### 描画の段取り

- 拡大・移動の途中は、粗い絵を毎フレーム描く
  - 解像度の倍率は 0.25〜1 の間で、フレームの間隔に合わせて変える
- 止まったら、細かい絵を横の帯に分けて何フレームかで作る
  - 1 帯は約 25 ms に収まる高さにする
  - できあがったら、表示中の絵と差し替える
  - 1 回の描画でまとめて作ると GPU の監視に止められる
- 反復回数を R32F のテクスチャに描き、配色は別のパスで付ける
  - 配色を変える・色を回すときは、反復をやり直さない
- 反復の上限は倍率から自動で決める
  - L = log₁₀(倍率) として 200 + 60L + 30L² にし、上限は 60000 とする
  - 渦の奥の ×10²⁹ では約 2.5 万回が要る
- 描画の画素数は 240 万画素を上限にする

### 配色

- 脱出の速さは ν = n + 1 − logₚ(log|z| / log R) とし、R は 1000 にする
- 色は log(ν + 1) × 色の間隔 + 色のずれ で配色の帯から取る。帯は端がつながる
- 陰影は、隣の画素との log(ν + 1) の差を法線にして光を当てる
- 集合の内側は黒にする
- 配色は夕焼け・炎・氷・墨・墨と朱・虹の 6 種で、既定は夕焼けにする。図の色はテーマに依らない

## 色

- 図・浮かぶ枠・図に重ねる部品は暗い地にし、テーマに依らない
- 橙（`--accent`）は LED と、板のつまみ・ジュリア集合の c の十字だけに使う

## カードの図柄（2026-11-19）

- カード案の H 案（D 案の左を B 案にし、点 c を重ねたもの）を区切り線なしで描く
- 左に集合と |z_k| = 2 の線 8 本を描き、右に c のジュリア集合を描く。左の上に c の点を黄の塗りで重ねる
  - 左は幅 46 の入れ子の `<svg>` で切り抜き、線が右へはみ出さないようにする
- マウスを乗せると、左で線が外側から 1 本ずつ増える
  - 1 秒に 2.5 本で増え、今増えた線だけ黄にする
  - 8 本そろうと集合を塗る
- 右のジュリア集合は 0.9 秒ごとに c を変える
  - c は −1 → −0.12 + 0.74i → 0.2 → −0.5 + 0.3i の順
  - 1 周は左右とも 3.6 秒
- 止まっている絵は、線 8 本と塗った集合、c = −1 のジュリア集合である
- 輪郭は脱出の速さの等値線をマーチングスクエアで閉じた path にし、`card-art.ts` の中で計算する
- 不採用の案は潜る・反復の輪郭・式の変形・ジュリア集合・べき・色の帯、それに点 c のない G 案

## しくみ

- 図の下に「しくみ」の枠を置く。工程は次の 5 つ
  1. z ← z² + c をくり返し、発散する点としない点に分ける
  2. 発散の速さで着色（見出しと本文の語はユーザーの指定、2026-11-19）
  3. 倍率が 10⁴ を超えると隣の画素が同じ座標になり正確な描写ができなくなる（本文はユーザーの指定、2026-11-19）
  4. 基準の点を 1 つだけ正確に計算し、ほかの点は差だけを追う
  5. 差がずれたら基準の初めへ戻して続ける
- 3 は、単精度のまま計算した絵と倍精度の絵を左右に並べて見せる
- 図はカードに指を乗せると初めから順に動く（[page.md](../page.md#しくみの枠)）
  - 1: 0 と −1 を行き来して円の中に残る軌道（c = −1）と、11 歩さまよってから円をわずかに抜ける軌道（c = −0.89 + 0.28i）を 1 点ずつ伸ばす。抜けたら「発散」の札を出す
  - 2: 回数の上限を増やし、外側から色を付ける
  - 3: 二重の渦へ ×20 から ×2×10⁶ まで 8 段で拡大する
  - 4: 2 つの軌道と差を 1 歩ずつ進める
  - 5: 基準の番号の線を左から伸ばし、初めへ戻した所に点を打つ
- 動作原理と式の枠には、摂動法・リベース・diffabs・BLA の式と出典を置く
