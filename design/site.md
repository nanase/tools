# サイト全体

上部バー・メニュー・トップ・色・動きの決まりである。

## 上部バーとフッター

- 上部バーは濃色にする。左にロゴとサイト名、右にテーマ切替とメニューを置く
  - どちらのボタンもアイコンだけにする
  - テーマ切替はメニューの左に置く
  - トップへはロゴで戻る。「一覧」のようなリンクは置かない
- ツールページで見出しが上部バーの下に隠れたら、サイト名の表示をページ名に切り替える
  - 切り替わった状態で押すと、ページの先頭に戻る
- フッターは注記の一文と GitHub アイコンだけにする
- パンくずリストは置かない

## メニュー

- カテゴリ別のツール一覧と絞り込み欄だけを置く。下部にリンクは置かない
- Ctrl+K で開く
- 左にカテゴリ、右に選んだカテゴリのツールを並べる（2026-10-31、案 A）
  - 開いたときは今のツールのカテゴリを選んでおく。トップでは先頭のカテゴリ
  - カテゴリはマウスを乗せても押しても矢印キーでも切り替わる
- PC ではツールをカードの図柄付きで 3 列に並べる
- スマホでは上部バーの下を埋め、図柄と名前の行にする
- 絞り込み中は全カテゴリから当てはまるツールを出す。カテゴリの数は当てはまる数にする
- LED は今のツールとそのカテゴリにだけ点ける

## トップ

- キャッチコピーと、公開中・準備中の件数は出さない
- 絞り込み欄の上に「Tools + Simulators」の見出しは出さない（2026-09-27）
  - 読み上げ用の h1 だけ残す。モックには見出しが残っている
- 準備中のツールは破線の枠と「準備中」の表記で区別する。公開中の表示と LED は出さない（2026-09-27）
- 絞り込み欄は枠で囲まない（2026-09-27）
- ツールは「一覧」と「カード」の 2 通りで並べる（2026-11-13、案 C 改）
  - 切り替えはアイコンだけのボタンにする
  - 既定は一覧で、カードを選んだときだけ保存する
  - カテゴリのボタンは置かない。件数は絞り込み欄の中に出す
- 一覧はカテゴリごとの箱を段組みにし、箱の中に小さな図柄と名前の行を並べる
  - 説明文は出さない
  - 行の図柄は止めたままにする
  - マウスで乗せたときと、キーボードで行へ移ったときは、その行のカードを横に浮かべて図柄を動かす
  - スマホでは箱を 1 列にし、箱の中を 2 列にする
- カードは今までどおりカテゴリごとの棚に並べる

## 色

- オレンジ（`--accent`）は LED と現在地の印だけに使う
  - メニューの LED、再生中などの LED
- 選択状態はインク色の塗りにする
- 強調は色ではなく、文字の大きさと太さで表す
- 信号色は波形と回路図の範囲だけで使い、UI の装飾に流用しない
  - ch1 は黄で出力、ch2 はシアンで C1 の電圧
- スペクトログラムはテーマに依らず黒い地にする（2026-10-01）
  - 色は強度の弱い順に 黒 → 紫 → 青 → 緑 → 赤 → 白。これもテーマに依らない
- 入力レベルのメーターは標準の緑にし、−3 dBFS を超えた分は警告色にする（2026-10-01）
  - audio-mockup.html の灰色から変えた
- 初期の配色は CSS の `prefers-color-scheme` だけで決め、JS に頼らない
  - ページを読み込むときにトランジションを走らせない
- ページだけの色に紫を使うときは、明るいテーマで #a03c8c、暗いテーマで #e58ad6 にする
  - 音律とうなりだけは #8a3fb0・#d197ff
- ページだけの色は [pages/](pages/) の各ページの「色」にある

## 動き

- テーマ切替・メニュー・吹き出し・開閉にはトランジションを付ける
- OS で動きを減らす設定がオンのときは、動かさずに切り替える
- マウスを乗せて動かすもの（上部バーのアイコン）は、マウスのときだけ動かす
  - タッチと、動きを減らす設定のときは動かさない
  - カードの図柄はタッチでも動かす（[card-art.md](card-art.md)）
