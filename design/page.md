# ツールページ

どのツールページにも共通する枠・配置・数値・保存の決まりである。入力の行は [input.md](input.md)、楽器の演奏の枠は [instruments.md](instruments.md) にある。

## 枠

- 枠は C 案の形にする。背景のない細い線で、見出しを枠線の上に載せる
- 補足（「定常状態」など）とボタン（E6/E12/E24）は、枠線の上の右端に載せる
- 動作原理と式の枠は初めは閉じる
  - 閉じているときは見出しの載った水平線だけにする
- ほかの枠も見出しを押して開閉できる。初めは開く（2026-10-22）
  - 閉じても、枠線の上の右端の補足とボタン（再生・停止、E6/E12/E24 など）は残す
  - 開閉はブラウザに保存し、読み込み直しても戻す。描く前に戻すので、開いた枠が閉じて見える動きは出ない
- 開閉しない枠はページ上部で幅いっぱいに置いた中心の図と、関連ツールだけにする
  - 中心の図はエンジン・指板・管と鍵盤・鍵盤と弦・空・トランペット・メータ・ヴァイオリン・アクションと段階
  - 2 列のページはすべての枠を開閉できる

## 配置と表示

- 説明文は常には出さない。見出しの右の小さな「?」から吹き出しで出す
- 操作説明の段落は置かない。UI だけで使い方が分かるようにする
- 入力は A 案のパラメータ表の形にし、列見出しは置かない
  - 行の形は [input.md](input.md) に従う
  - プリセットは小さい順に並べる
  - 入力中は結果を動かさない。Enter か欄の外で確定する
  - 項目の補足は常には出さない。項目名に点線を引き、ホバーかタップで吹き出しに出す（2026-09-27）
- 枠全体の表示を切り替える選択肢（フィルタの種類、コイルの形、入力元、再生）は、枠線の上の右端に載せる（2026-09-27）
  - 開始・停止のような二択は枠線の上の右端の LED 付きの小さなトグルにする。二択だけの行は置かない（2026-10-01）
  - 楽器のページの演奏の枠は例外で、右端には状態だけを出す（2026-10-18、[instruments.md](instruments.md)）
- 図の表示を変える設定は図の下に「表示の設定」などの見出しでまとめて畳む（2026-10-01）
  - 時間軸・振幅・トリガ、周波数軸・強度の範囲など
  - 形は入力の「その他」と同じ（2026-10-07）
- スピーカーで鳴らす操作は「音」「モニター」などの別の枠にする（2026-10-01）
  - 枠線の上の右端に再生・停止、中に音量（初期値 −30 dB）を置く
- 音声の入力元の初期値はマイクにし、どの入力元も止めた状態で始める（2026-10-01）
  - audio-mockup.html のテスト信号から変えた
  - マイクの間はハウリングを避けるためモニターを使わない。モニターの枠ごと畳んで、開けなくする
- 計算結果は B 案の形にする
  - 周波数を全幅で大きく出し、残りを罫線で区切って並べる。最下段の下に線は引かない
  - 「理想素子モデル」のような注記はフッターと重なるので置かない
  - 枠の幅に合わせて 2・3・4 列に並べる。補足の行が長い結果は 3 列までにする（2026-10-01）
  - PC では計算結果が画面にない間だけ画面の下に要約の帯を出す（2026-10-01）
- 出力波形は C 案のオシロスコープ表示を英語表記ごと使う
  - カーソル位置の読み値は表示窓の下に右寄せで出す（2026-10-01）
  - 1 つの枠で表示を切り替えるとき（波形とリサジュー、スペクトラムとスペクトログラム）は、図の下の設定も入れ替える。両方に効く設定は残す（2026-10-01）
- 回路図は B 案のものを使い、出力波形の下に置く
- 関連ツールはスマホでは 3 件、それより広い画面では 1 行に収まる件数だけ出す

## 動いても場所を変えない

操作・再生・計算のたびに行が折り返したり、文や行が出たり消えたりすると、下の枠が上下に動いて使いにくい。スマートフォンの幅で特に目立つ（2026-11-11 のユーザーの指摘。ギターの演奏中のコード名）。動く文字は、出る前から場所を取っておく。

| 動く文字 | 決まり |
| --- | --- |
| 行の知らせ | 印と吹き出しに出す（[input.md](input.md)） |
| 使わない行の理由 | 欄の中に 1 行で出し、はみ出す分は … で省く |
| 計算結果の値・補足・注意 | 1 行にし、はみ出す分は … で省く。補足と注意は空の間も 1 行を取る |
| 図の上下の表示の行（.sbar） | 1 行にし、最後の表示だけを … で省く。大事な表示から並べる |
| 演奏の枠の小節と時刻 | 狭い枠ではいつも 2 行。折り返すかは枠の幅だけで決める |
| 工程ごとの説明・手法の説明 | `.hh` の `data-ph` に最も長い文を書き、その高さを取る |
| 1 行の値の幅 | `.hw` の `data-ph` に最も長い値を書く |
| 表・一覧（中身の量で行数が変わる） | 高さを決めて、中を縦にスクロールさせる |

- … で省いた文字は、指すか押すと吹き出しで全文を出す（lib/bubble.ts）
- 中身が変わらない文（凡例・説明の補足など）は `.static` を付けて折り返す（ユーザーの判断、2026-11-12）
  - 図の上下の凡例は `.sbar.lg` でもよい
  - 付けた文が変わって揺れれば、検査で見つかる
- 吹き出しはページに重ねて出し、開いても閉じても下の行を動かさない
- 出る・消える表示は `hidden` ではなく `visibility` で隠し、場所を残す
- 例外として、次のものは動いてよい（ユーザーの判断、2026-11-12）
  - 表示の切り替え（単独・比較・一覧、方式など）で行や枠が出る・消える
  - 図そのものの大きさ
  - 動作原理と式の枠の中
  - 入力した文字の長さで決まる欄（正規表現の入力など）。`data-shift="ok"` を付けて検査から外す
  - 絞り込みなどの切り替えで中身ごと入れ替わる表。同じく `data-shift="ok"` を付ける
- 新しいページは `bun run layout-shift <id>` で確かめる（[DEVELOPMENT.md](../DEVELOPMENT.md#画面の揺れ)）

## 実践としくみの並び

触って結果を見る枠を上に、しくみを順に追う枠を下に置く。まず触って結果を見られるようにするためである。2026-11-03 に MP3 のページで始め、今後はほかのページもこの順に寄せる見込みである（ユーザーの判断）。

- しくみの枠は工程ごとの小さな図と短い説明で順に見せる
- 動きを減らす設定では止めて工程を終えた絵を出す

## 単独・比較・一覧

アルゴリズム・データ構造と画像の拡大縮小のページは、図の枠の右上で 単独・比較・一覧 を切り替える。初めは単独にする。

- 比較は図を並べて見比べる
- 一覧は組み合わせの表にする。マス・行の名前・列の見出しから単独や比較へ移れる
- 何を比べ、押すとどこへ移るかはページごとに違う。各ページの「画面と操作」にある

## 数値と式

- 音声の振幅はフルスケールを 1 とした値（FS）と dBFS で表す（2026-10-01）
  - 実効値・ピーク・スペクトラムのどれで測っても、正弦波が同じ dBFS になるようにする。AES17 の決め方である
- 計算結果と測定値は有効数字の桁をそろえ、末尾の 0 も残す（例 440.30 Hz・1.000 kHz。2026-10-01）
  - 対象は結果の枠・要約の帯・カーソルの読み値・代入した式で計算した値
  - 数値欄・入力欄・プリセット・メッセージは末尾の 0 を落とす
- 分数は組み文字（⅓）を使わず「1/3」と書く
- 数式は本文中の記号も含めてすべて MathML で書き、出典を添える
- 動作原理と式は枠の幅いっぱいに組む（2026-10-09。段落の幅の上限 62ch を外した）
  - 節ごとに見出しを付け、段落を短くする。並列の事柄は箇条書き・記号の説明・表にする
  - 処理の流れは矢印でつないだ箱（.flow）、制御系はインラインの SVG で描く。Mermaid は重いので使わない
  - 式の箱では短い式を横に並べる
  - 出典は枠の最後に番号付きの一覧にし、用途と書誌を分けて並べる。本文には番号（[1]）を付ける
  - 文献に基づかない値や方法は「このツールで決めたこと」の節に箇条書きで並べる

## 設定の保存

- 入力と表示の設定はブラウザに保存し、開き直したときに戻す（2026-10-01）
- 見出しの右端に「設定をもとに戻す」アイコンのボタンを置く。保存した設定を消し、既定値で開き直す
  - 保存する設定がないページには置かない
- 動作の状態（JJY シミュレータの動作・停止、RUN・STOP、開始・停止）は保存しない
- 「その他」と「表示の設定」の開閉も保存する。既定値に戻した項目は保存から消す（2026-10-07）
- 枠の開閉も保存する（2026-10-22）
