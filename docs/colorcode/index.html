動作原理と式

抵抗器の値は、数字・乗数・許容差を表す色の帯で示します。4 本帯は数字 2 桁、5 本帯は数字 3 桁で、続く乗数の帯が 10 の何乗を掛けるかを表します。6 本帯は、さらに温度係数の帯を加えます。許容差の帯はほかの帯との間を広くあけて端に置くので、その反対側から読みます。許容差の帯がない 3 本だけの抵抗器は ±20 % です。

E 系列に載っているかは、有効数字 3 桁で比べます。E24 までの値は 2 桁で、E48 以上の 3 桁の値とは別の数列です。たとえば 2.2 は E6・E12・E24 に載っていますが、E48 以上にはありません（E96・E192 には 2.21 があります）。

R=(10d1+d2)×10m（4 本帯）R=(100d1+10d2+d3)×10m（5・6 本帯）Rmin=R(1−t),Rmax=R(1+t)（t: 許容差）ΔR=RαΔT（α: 温度係数、ΔT: 温度の変化）Em:10i/m(i=0,1,…,m−1)を 2 桁（E48 以上は 3 桁）に丸めた値
