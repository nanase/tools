動作原理と式

直列につなぐと、抵抗とインダクタンスは和に、静電容量は逆数の和の逆数になります。並列ではその逆です。インダクタは素子どうしの相互インダクタンスを考えません。

n 本のつなぎ方はどれも、より少ない本数の 2 組を直列か並列にしたものに分けられます。そこで片方の組を列挙し、もう片方は目標から必要な値を逆算して、値を小さい順に並べた表から最も近いものを二分探索で選びます。使う値は、E 系列のうち最小と最大の間にあるものから、目標と同じ値と除外した値を除いたものです。

R直列=R1+R2+⋯+Rn,1R並列=1R1+1R2+⋯+1RnL直列=L1+L2+⋯+Ln,1L並列=1L1+1L2+⋯+1Ln1C直列=1C1+1C2+⋯+1Cn,C並列=C1+C2+⋯+Cnε=X−XTXT×100%（X: 合成値、XT: 目標）Em:10i/m(i=0,1,…,m−1)を 2 桁（E48 以上は 3 桁）に丸めた値

出典: IEC 60063:2015 Preferred number series for resistors and capacitors（E 系列の値）
