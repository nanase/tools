Tools + Simulators

Web上で各種計算＋シミュレーションができるツール群です

制御

  • PID制御
    フィードバック制御の一種であるPID制御を各項を調整しながらシミュレートします。

電子回路

  • 受動素子組み合わせ計算機
    抵抗器、コンデンサ、インダクタについて、任意の値に近似できる組み合わせを探索します。
  • タイマIC 555 シミュレータ
    抵抗器とコンデンサによってタイマICの出力の変化をシミュレートします。

デジタルフィルタ

  • 双2次フィルタ
    各種フィルタ特性に対応する双2次フィルタ（バイクアッドフィルタ）の係数を計算します。

JJY

  • JJY シミュレータ
    電波時計などで利用されているJJYの信号をシミュレートします。

SVG

  • SVG テーマスキーマチェッカー
    ライトテーマとダークテーマによって、SVGの外観が意図したものになるかを確認できます。
