# 立体音響の録音の出典とライセンス

立体音響のページで鳴らす録音の出どころです。ファイルは [public/spatial-audio/](../../../public/spatial-audio/) にあります。

どれも CC0 かパブリックドメインです。ページの「録音の出典」の枠にも出しています。中身は [credits.ts](credits.ts) にあり、録音を足すときは両方を直します。

## どの録音にも共通の加工

- 区間を抜き出し、モノラル・48 kHz にした
- 低い音の雑音を高域通過で落とした（周波数は録音ごと）
- ピークを −1 dBFS にそろえ、MP3（96 kbps）にした
- Freesound の録音は、ログインせずに取れる試聴用の MP3（128 kbps）から作った。元の WAV に替える見込み
- 朗読は LibriVox の 128 kbps の MP3 から、文の切れ目で 20 秒ほどを抜き出した
