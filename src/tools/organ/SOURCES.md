# オルガン音響モデルの曲の出典とライセンス

オルガン音響モデルのページで演奏する曲の出典とライセンスです。曲の一覧は [SCORES.md](../../../SCORES.md) にあります。

「PDMX に収録」は、MuseScore の楽譜を集めたデータセット [PDMX](https://zenodo.org/records/15571083)（Long ほか 2024）に入っていることを示します。

データは [scores/](scores/) にあり、`bun run organ-scores` で作ります。
